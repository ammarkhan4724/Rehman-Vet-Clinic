# Rehman Vet Clinic

This repository contains the codebase and SEO tools for the Rehman Vet Clinic website.

## Tech Stack
- **Frontend:** React 19, Vite, Tailwind CSS v4
- **Language:** TypeScript (`.tsx`, `.ts`), HTML
- **Build Process:** Vite build process coupled with a Python static page generation script (`generate_all_pages.py`) to create SEO-optimized static pages.
- **Tools:** Python 3 for data processing, CDP (Chrome DevTools Protocol) scripts for SEO scraping.

## Architecture & Guidelines
- `src/` contains the React application components and styling.
- Python scripts (`cdp_*.py`, `build_full_pages.py`, `generate_master_seo.py`) handle automated programmatic SEO, keyword clustering, and static HTML generation for multiple location-service combinations.
- SEO data is stored in CSV and Excel files (e.g., Ahrefs exports, Keyword Clusters).
- The `dist/` folder contains the final output generated by `npm run build` (which runs `vite build && py -3 generate_all_pages.py`).
- Maintain the Python script dependencies and React component structure when working on programmatic pages.
